# Colonie

A local desktop workspace for people and their AI bots.

## Download

Get the latest build from the [Releases page](https://github.com/etalas-studio/colonie-releases/releases/latest).
Colonie runs on Mac with Apple silicon.

Early builds are not notarized yet. After opening the app once, go to
System Settings → Privacy & Security and click Open Anyway.

This repository only holds downloads and the files the app uses to update itself.
